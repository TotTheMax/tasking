# TUI scroll deltas move the viewport down; the wheel rides on terminal arrow emulation

A scroll key/wheel delta (`dir`: `↑` = -1, `↓` = +1) in the TUI scrolling views means "move the viewport down the content" — toward later lines in Config/Activity-detail and toward newer entries in Log/Activity views — so every scroll helper clamps `start + dir` and pause anchoring (ADR 0019) stays untouched. The Log view initially shipped the inverse (`start - dir`), making ↓ show older entries; that was a bug against the shared convention, not a deliberate inversion. Native mouse tracking (SGR `\x1b[?1000h`/1006) is deliberately not enabled: alt-screen terminals already translate wheel events into ↑/↓ arrow keys, so the wheel follows the same path for free, and enabling real tracking would add escape parsing and cost the user native text selection.
